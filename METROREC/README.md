# METROREC – Sistema de Informações e Planejamento do Metrô

Projeto acadêmico desenvolvido em Python com Tkinter.

## Objetivo

Simular um sistema desktop de informações do metrô, permitindo consultar as linhas Jaboatão, Camaragibe e Sul, estações, horários, tarifas, status da operação e planejamento de viagens.

## Tecnologias

- Python
- Tkinter
- ttk
- Bibliotecas padrão do Python

## Funcionalidades

- Tela inicial com as três linhas
- Dashboard
- Consulta de estações
- Busca de estação
- Consulta de horários
- Próximo metrô
- Consulta de tarifa
- Status das linhas
- Planejamento de viagem
- Integração entre linhas
- Área de controle do sistema
- Relógio em tempo real
- Validação de dados

## Estrutura

- `main.py`: inicia o programa.
- `dados.py`: guarda linhas, estações, horários e configurações.
- `interface.py`: interface gráfica e navegação.
- `viagens.py`: regras de busca e planejamento de viagens.
- `utilitarios.py`: funções auxiliares.

## Como executar

No terminal, dentro da pasta do projeto:

```bash
python main.py
```

## Observação acadêmica

Os dados foram organizados como uma simulação para fins acadêmicos e podem ser alterados durante a execução pelo módulo de controle do sistema.
